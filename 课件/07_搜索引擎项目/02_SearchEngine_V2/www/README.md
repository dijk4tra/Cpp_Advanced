# SearchEngine V2 Web UI

此目录提供 `search_server` 内置 HTTP 服务使用的前端文件：

```text
index.html    前端页面
styles.css    minimalism / swiss 风格样式
app.js        浏览器端交互逻辑
```

运行方式：

```bash
cd 课件/07_搜索引擎项目/02_SearchEngine_V2
./bin/search_server
```

浏览器访问：

```text
http://127.0.0.1:18888
```

端口说明：

```text
8888   原始 TCP/TLV 服务
18888  浏览器 HTTP 服务
```
